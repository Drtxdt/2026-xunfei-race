# 全国总决赛补充规则适配

适配依据：2026-08-14 发布的第 21 届全国大学生智能汽车竞赛讯飞创意组“智慧工厂”全国总决赛规则补充说明。

## 已实现

### 坡道通行

- 在任务 1 到任务 2 的交接阶段，从地图标定入口进入坡道中心线。
- 使用 `/odom` 保证连续前进距离和横向偏移，使用 `/imu` 判断上坡、平台、下坡和离开坡道。
- 针对 38 cm 宽、1500 mm 长、230 mm 高、25°/22° 坡面设置分段速度。
- 横向偏移、横滚角、俯仰角或传感器时效越界时立即进入故障，不继续盲行。

现场必须复核 `competition.yaml` 中的 `ramp_entry_x/y/yaw` 和 `ramp_traverse_distance_m`。默认值来自当前地图坐标，不代替国赛现场标定。

### 红绿灯快速切换与停止线

- 保留现有五分类 RKNN，不改变模型输出顺序；在同一交通灯 ROI 内增加紧凑黄色灯体 HSV 检测，输出 `yellow_light`。
- 绿灯方向确认后立即启动对应巡线控制器，不再等待约 3 秒的方向语音后才起步。
- 以停止时“前轮到停止线的视觉距离”加安全余量作为越线里程阈值。
- 前轮尚未越线时，黄灯、红灯或无有效信号均停止；前轮越线后锁存通行，之后变红也继续通过。
- 越线后才异步播报方向，巡线控制器不重启，避免丢失 2 秒窗口。

### 巡线挡板避障

- 三条终点巡线控制器只向 `/track_end_stop/raw_cmd_vel` 发布原始速度。
- `national_obstacle_avoidance_mux.py` 是唯一向 `/cmd_vel` 发布的节点，避免速度指令竞争。
- 激光雷达连续确认前方挡板后，选择净空更大的一侧，麦轮横移离线；前方完全净空后前进绕过挡板，再按里程横移回原线并低速重捕获。
- 横移距离不是固定猜测：至少横移 0.24 m，并持续到挡板离开前向安全走廊；超过 0.82 m 仍未净空则停车报错。
- 避障只触发一次，且启动延时 4 秒，减少把路口设施误判成赛道挡板的风险。

## 上车前必做标定

1. 在实物坡道前复核入口中心、航向、连续通过距离和 IMU 正负方向；低速空载完成至少 5 次无停车通过。
2. 用正式红绿灯采集黄灯画面，检查 `/traffic_light_rknn_test/debug_image` 中黄色框只覆盖灯体，并按现场光照调整 HSV 与面积阈值。
3. 分别在四个规则图示绿圈位置摆放挡板，复核雷达左右净空、最大横移和通过距离，确认车体任何部位不接触挡板且驶出/驶回均位于虚线段。
4. 检查 `/national_obstacle_avoidance/status` 的状态顺序为 `FOLLOW → STOP → SHIFT_OUT → PASS → SHIFT_BACK → REACQUIRE → COMPLETE`。

## 关键参数

- 坡道与停止线：`src/ucar_2026_competition/config/competition.yaml`
- 黄灯检测：`src/ucar_2026_traffic_light_rknn_test/config/traffic_light_rknn_test.yaml`
- 挡板避障：`src/ucar_2026_track_end_stop/config/national_obstacle_avoidance.yaml`

参数均采用安全失败策略：传感器陈旧、无可用绕行侧、横移超限或姿态超限时输出零速度，不进行开环盲行。
