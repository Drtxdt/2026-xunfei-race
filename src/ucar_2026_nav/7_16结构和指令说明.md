# 7_16导航包和指令说明
# 结构：
```
my_planner: 自写控制器，当前没有启用，由于视觉触发导航效果不好，后续可能使用用来完成视觉触发导航的最后一段
ucar_controller: 车的底层驱动
ucar_map: 用于存储地图和建图launch
ucar_nav: 导航核心配置参数文件和launch
test_vision2nav: 完成仓储识别后触发导航完成最后进入仓库的动作，当前依然使用move_base实现，后续有待优化
```
# 指令

```bash
# 启动底层驱动和导航栈
roslaunch ucar_nav ucar_amcl_nav.launch

# 发送单点到二维码区（测试）
roslaunch simple_navigator navigate.launch

# 通过pgm取导航点
roslaunch map_goal_picker pick_goal_on_map.launch

# 回车模拟视觉被触发完成最后一步导航
roslaunch vision_triggered_navigator vision_triggered_navigator.launch

# 视觉通过话题触发
roslaunch vision_triggered_navigator vision_triggered_navigator.launch trigger_mode:=vision
```
